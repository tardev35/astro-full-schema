ปิด Email Address Obfuscation ซึ่งเป็นตัวที่ทำให้ Cloudflare ยัด /cdn-cgi/scripts/…/email-decode.min.js เข้าไปในหน้าเว็บแบบ render-blocking เมื่อเจออีเมลในหน้า

สร้าง token ที่ My Profile → API Tokens → Create Token → Custom token ให้สิทธิ์ Zone · Zone · Read และ Zone · Zone Settings · Edit แล้วเลือก Zone Resources เป็น All zones
token ไม่ถูกเขียนลงดิสก์และไม่ถูก log — ส่งผ่าน request ไป Cloudflare แล้วทิ้ง
